# Escape The Rooms

A 10-level puzzle-adventure game where players explore mysterious rooms, collect keys, unlock gates, solve puzzles, avoid traps, and escape.

## Features

- 10 handcrafted levels
- Progressive difficulty
- Key and gate mechanics
- Puzzle challenges
- Traps
- Enemy/stealth sections
- Checkpoints
- 3-heart health system
- Level progression
- Level select
- Final victory celebration
- Premium fantasy-game UI

## Tech Stack

- JavaScript
- HTML5 Canvas
- CSS

## How to Run

```bash
npm install
npm run dev
```
